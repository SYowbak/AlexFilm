# Інструкція з безкоштовного деплою AlexFilm на Render.com

Цей проект повністю налаштований для безкоштовного запуску 24/7 у хмарі на **[Render.com](https://render.com/)**. 
Ваш комп'ютер можна буде вимикати — сайт працюватиме самостійно.

---

## 1. Завантаження проекту на GitHub

Якщо проект ще не завантажений на ваш GitHub:

1. Створіть новий **порожній** репозиторій на [GitHub](https://github.com/new) (наприклад, з назвою `alexfilm`). Можна обрати Private або Public.
2. У терміналі вашого проекту (в папці `Movie`) виконайте команди:

```powershell
# Ініціалізація git
git init
git add .
git commit -m "Підготовка до хмарного деплою на Render"

# Підключення до вашого репозиторію на GitHub (замініть URL на ваш)
git branch -M main
git remote add origin https://github.com/ВАШ_НІК/alexfilm.git
git push -u origin main
```

---

## 2. Розгортання на Render.com (Безкоштовно)

1. Перейдіть на **[Render.com](https://render.com/)** і натисніть **Sign In** (найпростіше — увійти через **GitHub**).
2. Натисніть кнопку **New +** (вгорі праворуч) і виберіть **Blueprint** (або **Web Service**):
   * **Варіант A (Найпростіший через Blueprint):**
     * Виберіть **Blueprint** -> підключіть ваш репозиторій `alexfilm`.
     * Render автоматично прочитає готовий файл `render.yaml` з налаштуваннями:
       * Регіон: `Frankfurt` (найближчий до України, мінімальна затримка).
       * Тариф: `Free` ($0/місяць).
       * Команди збірки та запуску вже прописані.
     * Натисніть **Apply**.
   * **Варіант B (Вручну через Web Service):**
     * Якщо створюєте вручну як **Web Service**:
       * **Name**: `alexfilm` (або будь-яка інша назва).
       * **Region**: `Frankfurt (EU Central)`.
       * **Runtime**: `Node`.
       * **Build Command**: `npm run build`
       * **Start Command**: `npm run start`
       * **Instance Type**: `Free`.
       * В розділі **Environment Variables** додайте:
         * `NODE_ENV` = `production`
         * `TMDB_API_KEY` = `0aae6e08fea10578e99f3da447ac2fcb` (або ваш особистий ключ TMDB)

3. Натисніть **Deploy Web Service** (або **Create Web Service**).

---

## 3. Готово!

Через 2–3 хвилини Render збере застосунок і видасть вам безкоштовне посилання з захищеним SSL (HTTPS):
👉 **`https://ваша-назва.onrender.com`**

Цим посиланням ви можете ділитися з друзями! Фронтенд, пошук і відеопотоки працюватимуть на єдиному домені.

---

### Особливості безкоштовного тарифу Render:
* **"Холодний старт"**: якщо сайт не відвідували понад 15 хвилин, безкоштовний сервер Render "засинає". Коли хтось відкриває його знову, сервер прокидається приблизно за 30–50 секунд. Після цього все працює швидко й плавно.
* **Трафік**: включено 100 ГБ безкоштовного трафіку на місяць, чого цілком достатньо для вас і компанії друзів.
